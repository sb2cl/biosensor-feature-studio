# Figure 1 / JBE software scope (GitHub Pages beta v0.2.1)

**Figure 1** should depict the modular workflow **measured time courses -> calibrated, QC'd replicate dose-response -> system-aware estimators -> uncertainty + interpretability -> performance/design descriptors**. BioSensor Feature Studio supplies a public-browser implementation of the middle analysis layers.

Frozen MATLAB FdeR (11D historical VBMC) and pLux P2/P3k/P3l numerical results remain canonical. Python estimator equivalence and uncertainty-distribution regression testing are in progress; show the deployed application as a demonstrator, not proof of exact replication. The browser site does not directly execute raw-data temporal extraction, mechanistic ODEs, VBMC, or independent RBS-q propagation yet.

The hosted synthetic examples are educational; source paper data are not bundled. Link the final tested GitHub Pages URL and versioned source repository in Code Availability only after deployment and validation.
