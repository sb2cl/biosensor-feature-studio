# BioSensor Feature Studio v1.0.0

**Release notes (ready for review; publish only after successful GitHub Actions).**

First citable software snapshot of BioSensor Feature Studio from SB2CL
(Institute ai2, Universitat Politècnica de València).

Features: locally executed browser analysis; synthetic example and CSV
templates; FdeR- and pLux-specific dose-response estimators; within-dose
replicate bootstrap; complete correlated posterior curves; response-quality
diagnostics; explanatory uncertainty intervals; exploratory joint design
thresholds; CSV and JSON exports.

Software authors: Yadira Boada (0000-0001-5677-2702) and
Alejandro Vignoni (0000-0001-9977-7132).
Copyright (c) 2026 Universitat Politècnica de València. Code license: MIT.

Scientific boundaries: normalized input only; no raw-reader calibration,
ODE/VBMC fitting, RBS uncertainty model, or real-world guarantee that
design constraints will be met. Numerical MATLAB identity is not claimed;
see `VALIDATION_STATUS_v1_0_0.md`.

Web: https://sb2cl.github.io/biosensor-feature-studio/
Repository: https://github.com/sb2cl/biosensor-feature-studio
